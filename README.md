A zero-dependency React compound component that renders an animated number input, digits are animated in as they are being typed, selecting and replacing a single digit gets you the popluar barrel wheel effect made famous by [NumberFlow](https://number-flow.barvian.me/).

## Demo

https://hello-mat.com/design-engineering/component/number-flow-input

## Features

- Zero runtime dependencies (just React `>= 18`)
- Renders a content editable input, and a syncrhonized hidden real input for integration in forms 
- Ships with full TypeScript types
